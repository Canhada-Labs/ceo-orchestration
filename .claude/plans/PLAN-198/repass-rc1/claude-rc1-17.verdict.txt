  - On Python 3.9, a symlink loop at <project>/CLAUDE.md makes Path.resolve() raise RuntimeError on the same path.

- Claude Code still applies the layer: the JSON is valid, and the glob simply matches nothing.
- This is a fail-open on input the security matcher cannot process, which inverts item 2. Before this delta, an attacker could hide only their own layer, by making it unparseable, which Claude Code also rejects.
- Precondition: write access to a settings layer — the exact case the detector exists for. Not P0, because both detectors are advisory and the project/local settings files stay canonical-guarded.
- Minimal fix:
