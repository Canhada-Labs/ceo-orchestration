P2 FOLLOW-UPS
P2-1 — .claude/hooks/_lib/_audit_emit_parts/writer.py:603-604, 687, 758-761.
- Defect: the fallback branch reads `line` before it exists.
- Scenario: the audit directory or the lock directory exists but is not writable.
  1. FileLock calls os.open (filelock.py:144), which raises PermissionError before line 687 builds `line`.
  2. The `except (OSError, PermissionError)` branch calls `_write_fallback(line)`, which raises UnboundLocalError.
  3. The outer `except Exception` calls _breadcrumb, which writes into the same unwritable directory and fails silently.
  4. The event is lost, with no /tmp fallback and no banner. This contradicts the F-CHAOS-1 comment.
- Reach: only the sync path, meaning the spool kill-switch is on or the spool silently dropped the event.
- Test gap: test_audit_emit.py:1183 only fails at log.open, after `line` exists.
- Origin: the code looks carried over unchanged; the M9 comment at lines 741-748 already notes the same scoping problem for the timeout branch.
- Minimal fix: in the OSError branch, serialize from `event` the same way the FileLockTimeout branch does.

P2-2 — writer.py:42-51, 76, 87.
- Defect: the fallback file /tmp/ceo-audit-fallback-<user>.log has a predictable name, and both open("a") and os.chmod follow symlinks.
- Scenario: on a shared host (macOS has no protected_symlinks), another user plants a symlink at that path. The victim's degraded writes then append event JSON to any file the victim can write, and set that file to mode 0600.
- Origin: carried over by the move.
- Minimal fix: open with os.open(O_WRONLY|O_APPEND|O_CREAT|O_NOFOLLOW, 0o600) and use fchmod on the descriptor.
