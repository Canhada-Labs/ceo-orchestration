All five files exist in .claude/scripts/.

- Python 3.9 and the standard library. The parts import nothing outside the standard library and the repo's own _lib. They use shutdown(cancel_futures=True), which needs 3.9 or later, and string annotations. Nothing newer than 3.9.

The upgrade manifest walks the whole .claude/hooks tree. The canonical guard ".claude/hooks/_lib/**/*.py" (canonical_edit/guards.py:34) covers the parts.
- Fail direction. Advisory checks fail open. The boot-lesson render gate (candidates_lessons.py _validate_boot_lesson) fails closed when the validator is missing or raises; that is a security matcher on input, which is the right direction. No inversion found.
- Adopter impact. The only new check is main_checkout_state, and it is yellow only, which does not change gate_pass. CHANGELOG lines 340 and 479 declare it. In this payload, nothing disables hooks, changes the model or effort, or blocks a session.
- Declared conditions. None is contradicted by this payload. Condition 7 holds: ceo-boot.py keeps its path and its logic moves to _lib.
