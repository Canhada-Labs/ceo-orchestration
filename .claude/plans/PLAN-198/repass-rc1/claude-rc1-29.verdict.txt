P1 — CHANGELOG.md:112-117 versus .claude/hooks/_lib/_contamination/cli_checks.py:131-138 and :193-261, and .claude/scripts/_contamination_inventory.py:28-144. Undeclared change to the verdict of a shipped CI gate, contradicted by the CHANGELOG.

- What actually changed: the term rule (Rule 1) now fails closed. It returns rc 2 where v1.4.2/v1.4.3-rc.1 returned 0 in four cases:
  - (a) any tracked path ANYWHERE in the index is not valid UTF-8, or contains a literal U+FFFD (_index :46-52). Before, the path was decoded with errors=replace, read_bytes raised OSError, and the file was skipped. Rule 2 only refused such paths in docs/ or .claude/plans/.
  - (b) a tracked file exists but cannot be read, or is a FIFO, a device or a directory (_read_regular/_blob :58-95).
  - (c) a tracked symlink whose payload cannot be readlink'd (see P2-3).
  - (d) any disagreement between the walk and the index snapshots (:109-121).
- Other observable changes:
  - _SKIP_SUFFIXES no longer skips anything: regular .png/.pdf/.zip blobs that decode as UTF-8 are now matched.
  - The personal-path report now prints BEFORE the term report.
  - A Rule 2 rc 2 now returns before Rule 1 runs (cli_checks.py:208-212).
- None of this is in CHANGELOG [1.4.4], neither in a Fixed section nor in "What an adopter should know". Only the in-code census at check_contamination.py:439-469 states it.
- Failure scenario: an adopter's repository has one tracked file outside docs/ with a Latin-1 name, or a name that really contains U+FFFD. Their CI runs `bash .claude/scripts/check-contamination.sh` from templates/.github/workflows/validate.yml.template:87. It passes on v1.4.2. After `upgrade.sh --pin v1.4.4-rc.1` it exits 2 with "a tracked Rule 1 path is not valid UTF-8". Renaming is the only cure (no waiver exists), and the CHANGELOG told the adopter the contract had not changed.
- Impact: the direction is fail-closed, as §4 prescribes for a gate's input, and no session is blocked. The realistic trigger rate is low. The finding is the false CHANGELOG statement and the missing upgrade note.
- Minimal fix: add a CHANGELOG [1.4.4] Changed/Fixed bullet plus one line under "What an adopter should know", listing the new rc-2 classes (a)-(d), the end of the suffix skip, and the new report order. Alternatively, remove check_contamination.py from the "same way / observable contracts" sentence at :116.
