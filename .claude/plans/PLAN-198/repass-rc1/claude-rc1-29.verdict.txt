2. P2 — .claude/scripts/_contamination_inventory.py:76-81 and :89. For an index entry with mode 120000, _blob only calls os.readlink.
   - Under core.symlinks=false (the Git for Windows default), git writes the link as a regular file, so readlink raises EINVAL and every non-allowlisted tracked symlink makes Rule 1 return rc 2 on every run. Before this change, read_bytes() scanned that file.
   - A tracked symlink that is deleted, or left out of a sparse checkout, also returns rc 2, while a missing regular file is skipped (:87-88).
   - The ELOOP fallback does not handle EMLINK, which FreeBSD returns.
   - Rule 2 in the same gate already handles all three cases (_personal_path_read_nofollow).
   Minimal fix: on EINVAL, read the materialised file with _read_regular; on ENOENT or ENOTDIR return None; treat EMLINK like ELOOP.
