1. P2 — .claude/hooks/_lib/_audit_emit_parts/generic_dispatch_05.py:363. The message for an unknown action changed from `emit_generic: unknown action {action!r}` to `unknown audit action dropped: %s`, and now writes the raw action text without repr(). Failure scenario: a direct caller passes an action string that contains "\n". The text after the newline becomes a separate line in audit-log.errors that looks like a real breadcrumb (_breadcrumb at writer.py:236 does not escape it). The base version escaped it, and any check that matches the old message text no longer sees it. Fix: restore the base message with %r.

Fix: look the handlers up by name inside _dispatch_generic, for example `globals()[n] for n in (...)`.
