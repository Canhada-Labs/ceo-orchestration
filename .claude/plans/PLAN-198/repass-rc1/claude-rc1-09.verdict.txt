1. P2 (the one behaviour change in moved code; CI-only, fails closed, nothing triggers it today). Inputs that used to give one blocking site now crash the whole census.
   - Locations: .claude/hooks/_lib/_installer_write_safety/__init__.py:36, with syntax.py:6-10. Affected handlers: verdicts_b.py:141, verdicts_b.py:440, verdicts_b.py:447, commands.py:131, model.py:320, model.py:344, model.py:632, operands.py:35.
   - Cause: _bind_class clones each package class with `type(original)(name, original.__bases__, attrs)`.
     - The facade's ParseError is a clone P' whose base is Exception.
     - The facade's Incomplete is a clone I' whose base is the ORIGINAL syntax.ParseError, not P'.
     - So issubclass(facade.Incomplete, facade.ParseError) is False.
   - Effect: every bound `raise Incomplete(...)` (in _read_balanced, _read_dquote and lex) escapes the `except ParseError` handlers. In the monolith those handlers caught it and returned an indeterminate (blocking) verdict or a fallback.
   - build_logical_lines still works, because it catches `except Incomplete`, so whole-file parsing is unaffected.
   - Failure scenario: any scanned scripts/**/*.sh line such as `sed -e 's/${//' -e 's/}//' "$f"` (turning ${VAR} into VAR) or `sed 's/$(//'`.
     - The first goes _verdict_one_script -> _names_in_text("${") -> _expansion_refs -> _read_balanced and raises I', which commands.py:131 misses. The second raises I', which verdicts_b.py:141 misses.
     - The result is an uncaught traceback with exit 1. validate.yml:414 goes red without naming a site, --json emits no JSON, and --write-baseline cannot run until the shell line changes.
   - Fail direction stays CLOSED and there is no adopter impact.
   - A grep of the current scripts/ corpus found no line that triggers it, and no test exercises these handlers. That is why this is P2, not P1.
   - Minimal fix, either of:
     - in _bind_class, rebuild __bases__ from the already-cloned package classes (substitute namespace[b.__name__] for bases whose __module__ is in the package);
     - or return the original class for subclasses of BaseException.
     - Add a test asserting issubclass(mod.Incomplete, mod.ParseError) and that `sed 's/$(//'` yields an i-script-unparsed site.
