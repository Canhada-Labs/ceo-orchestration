   Minimal fix: read find's status after the loop, or run find into a temporary list first and check its exit code.
4. P2, .claude/scripts/ceo-backup.sh:253. `dirname "$rel"` without `--` fails on a name that starts with "-".
   Effect for a top-level file: only an error message on stderr.
   Effect for a subdirectory such as `-x/y.md`: mkdir does not create `-x`, the next cp fails, and set -e aborts the backup. It fails closed and loudly.
   Minimal fix: `dirname -- "$rel"`. The same line exists at ceo-restore.sh:322.
