P2-1 (carried): decoy branches make two structure tests pass vacuously.
- Where: .claude/hooks/_lib/audit_emit.py:473-480.
- Scenario: the facade's emit_generic has `if action == "tool_call_lifecycle_recorded"` and `if action == "settings_tamper_detected"`. Both do exactly what the fall-through line does. They exist only so that inspect.getsource(audit_emit.emit_generic) contains those comparisons, which .claude/hooks/tests/test_tool_lifecycle.py:541-563 and .claude/scripts/tests/test_ceo_boot_tamper_tripwires.py:521-525 require. The real scrub branches are generic_dispatch_04.py:62 and :159. If they are deleted, both tests stay green; the event would fall to default-deny, so fields would be lost, not leaked. The ghost-action guard test was updated correctly to walk _GENERIC_DISPATCH_HANDLERS.
- Minimal fix: remove the decoys and make the two tests call emit_generic with a forbidden field, then assert the field is dropped and the enum values are coerced.

P2-2 (carried): dead duplicate action registry.
- Where: .claude/hooks/_lib/_audit_emit_parts/actions.py:7-16, with actions_core.py and actions_extended.py (331 names).
- Scenario: the install() roster does not include these files (audit_emit.py:415-452); the runtime registry is the literal at audit_emit.py:45-377. A maintainer who registers a new action in actions_core.py, which .claude/scripts/env-inventory.json points at, gets no runtime effect, and the action is silently dropped as unknown.
- Minimal fix: delete actions*.py, or add a parity test pinning them equal to the facade literal.

P2-3 (carried, extended): the unknown-action breadcrumb lost repr escaping and can now raise.
- Where: .claude/hooks/_lib/_audit_emit_parts/generic_dispatch_05.py:363.
- Scenario: the removed code logged f"emit_generic: unknown action {action!r}"; the new code logs "unknown audit action dropped: %s" % action.
  - An action string with a newline is written raw into the audit-log.errors sidecar, which is not HMAC-chained, so lines there can be forged.
  - A tuple action is hashable, fails the membership test, and then makes the %-format raise TypeError. That breaks the never-raises contract, which the removed f-string kept.
  - Callers pass constants today, so exposure is low.
- Minimal fix: _breadcrumb(f"emit_generic: unknown action {action!r}").

P2-4 (new): the public emit_generic lost its docstring.
- Where: .claude/hooks/_lib/audit_emit.py:473.
- Scenario: the removed docstring documented the contract callers rely on: it never raises, it applies no redaction, and callers must redact free-text fields before the call. help() and IDE hovers now show nothing, so a new caller loses the instruction to pre-redact.
- Minimal fix: copy the original docstring onto the facade function.
