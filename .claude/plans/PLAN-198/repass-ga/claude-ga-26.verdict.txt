1. P2 - .claude/scripts/ceo-backup.sh:247 and :255. If $AUDIT_DIR/memory is itself a link to a directory, [ -d ] is true, but find with its default -P does not follow a link named on the command line, so it lists nothing. The archive gets an empty memory/ and the run exits 0 with no warning; the base version followed memory/. and backed the files up. Already raised as P2 #2 in rc1 claude-25 and unchanged in the GA. Minimal fix: `find -H "$AUDIT_DIR/memory" -type f -print0`, or a stderr warning when [ -L "$AUDIT_DIR/memory" ].
2. P2 - ceo-backup.sh:255. Bash ignores the exit status of a process substitution. An unreadable subdirectory gives a partial snapshot that is archived, checksummed, reported "ok" and entered into rotation; the old cp -pR aborted under set -e. Already raised in rc1 codex-25 and claude-25. Minimal fix: write find's NUL-delimited list to a temp file, check find's exit code, and abort before tar and rotation.
