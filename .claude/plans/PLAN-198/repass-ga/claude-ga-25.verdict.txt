P2 FOLLOW-UPS:
P2-1 .claude/scripts/audit-verify-chain.py:579-587 against its docstring at :46-47. The docstring says an illegible counter is rc 3, "rc 4 when the read is refused by permissions". But an os.lstat PermissionError on the counter (for example, a parent directory without search permission) is caught as a plain OSError and returns rc 3 "cannot stat"; only an os.open refusal gives rc 4. Scenario: an operator script that branches on rc 4 to mean a permissions problem misreads this case as a corrupt counter. Fix: catch PermissionError from lstat and map it to EXIT_PERM/STATUS_PERM_ERROR, or reword the docstring.
P2-2 .claude/scripts/audit-verify-chain.py:588-590. Only the first 64 bytes of the counter are read. A file whose first 64 bytes are digits plus whitespace, followed by junk, is accepted (for example "12" + 62 spaces + "xyz" is read as 12). This goes against "not plain decimal digits → rc 3". The impact is low, because whoever can write the counter can already lower it. Fix: read 65 bytes and refuse when more than 64 are present, or read up to EOF with a small cap.
P2-3 .claude/hooks/_lib/_audit_query/labeling.py:19-21 and :51. As a standalone module, _LABEL_STORE_PATH points to .claude/hooks/_lib/_audit_query/audit-log-labels.jsonl. _compute_label_hmac then builds .claude/hooks/_lib/hooks/_lib, a path that does not exist, and can silently fall back to the hardcoded chain key. These paths are correct only after the facade rebinds them, and no caller uses the module directly today. Scenario: a future caller imports labeling.cmd_label directly, writes labels inside the hooks tree, and computes HMACs with the wrong key. Fix: resolve both paths from the repository root, or make the module refuse to run unless it has been rebound.
P2-4 .claude/scripts/audit-query.py:214-224. _bind_query_functions overwrites any facade global that has the same name as a function in an extracted module. Today nothing collides. A future helper named read_entries or default_log_path in a module would silently replace the facade's own definition. Fix: assert that no cloned name is already bound to a facade-defined function, apart from the intended cmd_* delegates.
P2-5 .claude/scripts/audit-query.py:387-394. A leftover section header ("PLAN-080 Phase 1 — by-domain sub-command / Default window for by-domain") has no code under it. Fix: delete it.
P2-6 .claude/governance/function-length-grandfather.yaml:872-883. The audit-verify-chain.py verify/main entries carry sha256 values for the old bodies, and verify has grown to about 155 lines. The check is advisory in CI (validate.yml:287-290 runs it with `|| true`), so nothing breaks. Fix: refresh the entries or add a `# justified:` comment.
