1. **P1 — fix before rc.4**  
   **FILE:LINE:** `scripts/_framework_manifest_set.sh:152-153`, `scripts/install.sh:1300-1302`, `scripts/_framework_manifest_set.sh:413-421`, `scripts/uninstall.sh:217-232`  
   **Failure scenario:** The diff unconditionally adds `PLAN-SCHEMA.md` and `DEBATE-SCHEMA.md` to baseline enumeration. On a re-install over an adopter-customized schema, `install_one` preserves the existing file, but manifest generation hashes that preserved adopter content as framework-owned. A later normal uninstall sees the matching hash and deletes the adopter’s schema. This contradicts the candidate’s “never clobbering adopter edits” claim.  
   **Minimal fix:** Make schema ownership conditional on actual delivery or valid prior ownership continuity. An `EXISTS`-skipped schema must not enter a fresh install manifest. Add a positive control that seeds a custom schema, runs install, verifies the manifest omits it, and verifies uninstall preserves it.

2. **P1 — fix before rc.4**  
   **FILE:LINE:** `scripts/_framework_manifest_set.sh:844-847`, `scripts/_framework_manifest_set.sh:913-915`, `scripts/tests/test-night-mode-ignore-effect.sh:342-370`  
   **Failure scenario:** Both helpers equate presence of an exact ignore line with effective exclusion. For example, an adopter-owned `.claude/.gitignore` containing:
   ```gitignore
   /settings.local.json
   !*.json
   ```
   passes `grep -Fxq`, so install/upgrade appends nothing; Git’s later negation wins and `.claude/settings.local.json` remains visible. Under user ceremony, this nested file is the only protection, so the original night-mode leakage recurs. The seeded controls exercise only `/cache/`, not an overridden-but-present mandatory rule.  
   **Minimal fix:** Check effective Git ignore behavior, not textual presence. If a later rule negates a mandatory exclusion, append the exclusion after the winning negation or fail loudly. Add install and upgrade controls seeded with an exact exclusion followed by `!*.json`, asserting both night-mode artifacts remain ignored.
